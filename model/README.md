# Pretrained model access

The pretrained CBCT tooth and jawbone segmentation model is available upon reasonable request for academic and research purposes.

Please contact **[simaichen413@gmail.com](mailto:simaichen413@gmail.com)** with a brief description of your research purpose.

The model is provided as an nnU-Net v2-compatible archive named `nnUNet_413.zip` and can be installed directly:

```bash
nnUNetv2_install_pretrained_model_from_zip /path/to/nnUNet_413.zip
```

For model configuration and inference commands, see [MODEL.md](../docs/MODEL.md) and [INSTALLATION.md](../docs/INSTALLATION.md).
