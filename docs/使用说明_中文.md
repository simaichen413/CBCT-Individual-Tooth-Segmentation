# CBCT牙齿及颌骨分割模型使用说明

本项目使用 nnU-Net v2 的三维全分辨率配置，对CBCT进行牙齿、上颌骨和下颌骨的多类别分割，输出不同牙位的独立分割标签。

## 模型信息

- 数据集：`Dataset413_byscm`（ID 413）
- 模型：nnU-Net v2，`3d_fullres`
- 训练器：`nnUNetTrainerNoMirroring`
- 权重：Fold 0，`checkpoint_final.pth`
- 输入：单通道CBCT，NIfTI格式（`.nii.gz`）

## 安装与导入

安装兼容的PyTorch和nnU-Net v2环境：

```bash
pip install nnunetv2
```

设置`nnUNet_results`环境变量。macOS/Linux示例：

```bash
export nnUNet_results="$HOME/nnUNet_results"
mkdir -p "$nnUNet_results"
```

收到模型ZIP后，不需要手动解压，直接导入：

```bash
nnUNetv2_install_pretrained_model_from_zip /path/to/nnUNet_413.zip
```

## 分割推理

按照nnU-Net单通道命名要求准备影像：

```text
imagesTs/
├── case001_0000.nii.gz
└── case002_0000.nii.gz
```

运行：

```bash
nnUNetv2_predict \
  -i ./imagesTs \
  -o ./predictions \
  -d 413 \
  -c 3d_fullres \
  -f 0 \
  -tr nnUNetTrainerNoMirroring
```

模型仅包含Fold 0。输出为多类别整数标签，包含上下颌骨、32个FDI牙位类别和**下颌管**（标签ID 35，原始配置名为`seg5`）。完整映射见[标签说明](LABELS.md)。

## 内部验证

11例验证CBCT中，32个牙位类别的平均Dice为**0.9670**，上颌骨为**0.9696**，下颌骨为**0.9852**。具体结果见[验证指标](VALIDATION.md)。
